Icon-only circular button for toolbars, players, and card actions — always pass an `aria-label`.

```jsx
<IconButton aria-label="Play episode" variant="soft"><Play/></IconButton>
<IconButton aria-label="Share" variant="sticker"><Share2/></IconButton>
```

Variants: `ghost` (default), `soft` (clay tint), `sticker` (ink outline + offset). Sizes `sm | md | lg`.
