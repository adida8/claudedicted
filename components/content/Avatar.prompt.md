Round avatar — pass `src` for a photo or `name` to auto-render warm initials.

```jsx
<Avatar name="Mark Janssen" size="lg" ring="clay" spark />
<Avatar src="/me.jpg" name="Mark" size="md" />
```

Note: `spark` defaults to `sparkSrc="assets/spark.svg"` — set the right relative path if your page isn't at the project root.
